AI-Driven Cyber Threat Intelligence: Automated Threat Extraction and Analysis from Open and Dark Web Sources

An end-to-end AI-driven Cyber Threat Intelligence (CTI) pipeline designed to automate the collection, extraction, validation, and natural-language querying of threat data from unstructured open and dark web sources.

Overview

This ongoing research project addresses the challenge of triaging unstructured threat intelligence published across vendor threat reports, open-web security bulletins, and Tor-routed dark web forums. The system automates the ingestion, extraction, external validation, and relational modeling of unstructured threat material into a dual-store architecture (Knowledge Graph and Vector Index) accessible via a retrieval-augmented natural language interface.

Key Objectives & Architecture

  • Multi-Channel Ingestion — Collecting unstructured threat text from PDF reports, open-web security RSS feeds, and Tor hidden services via automated crawlers.
  • Domain-Specific Named Entity Recognition — Extracting threat actors, malware families, tools, vulnerabilities, and organizations using fine-tuned models such as SecureBERT-NER.
  • Indicator of Compromise (IoC) Extraction — Regex-based pattern extraction with automatic refanging for IP addresses, URLs, domains, hashes, and CVE identifiers.
  • Dual-Path Processing & Knowledge Graph Construction — Simultaneously populating a ChromaDB vector store for dense semantic retrieval and a Neo4j property graph anchored to the MITRE ATT&CK framework for relational reasoning.
  • External Validation Layer — Staging extractions in PostgreSQL and verifying indicators against authoritative external APIs (NVD, VirusTotal, AbuseIPDB).
  • Grounded RAG Query Engine — Combining dense semantic search and structured graph context to generate citation-backed analyst responses via local LLMs (Llama 3 via Ollama).
