Preventing Extraction-Time Hallucination in Cyber Threat Intelligence via Neuro-Symbolic Evidence Grounding

A novel Neuro-Symbolic Evidence-Grounding Framework that combines deterministic sub-span containment checks, syntactic dependency parsing, and STIX 2.1 / MITRE ATT&CK ontological disambiguation with generative LLMs to suppress extraction-time hallucinations in security knowledge graphs.

Overview

Automated construction of Cyber Threat Intelligence (CTI) Knowledge Graphs relies on extracting relational triples ⟨Subject, Predicate, Object⟩ from unstructured threat reports. While conventional rule-based extractors achieve high precision, they suffer from poor recall. Conversely, generative Large Language Models (LLMs) achieve high true-positive recall but suffer from severe parametric hallucination when co-occurring entities lack explicit relational evidence in the text. This ongoing project introduces a deterministic programmatic gating framework to suppress ungrounded LLM inference before execution.

Key Objectives & Architecture

  • Programmatic Evidence-Grounding Guards — Implementing a multi-level sequence of deterministic gating functions (Entity Sub-Span Containment, Sentence Boundary, Dependency Path Distance, and Lexical Trigger Guards) to reject candidate entity pairs prior to LLM escalation.
  • Zero-Cost Recall Preservation — Suppressing false-positive relation edges on distant and co-occurring negative entity pairs while preserving peak true-positive extraction performance.
  • Multi-Engine Extraction Framework — Developing a modular Python framework supporting local open-weight models (Qwen2.5-0.5B-Instruct, Llama 3 via PyTorch/Ollama) and cloud LLM backends.
  • STIX 2.1 / MITRE ATT&CK Ontological Disambiguation — Enforcing domain-range object typing constraints to resolve schema-level ambiguities (e.g., distinguishing USES vs. EMPLOYE vs. EXPLOITS).
  • Benchmark Suite & Reproducibility Pipeline — Standardized evaluation pipeline across 7,393 CTI relation extraction samples derived from Mandiant APT1, FireEye APT28, and MITRE ATT&CK STIX 2.1 repositories.
