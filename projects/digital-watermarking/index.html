Overview

ChromaGuard Pro is a robust, adaptive, and zero-knowledge blind invisible image watermarking framework designed for content provenance, forensic tracking, and protection against generative AI deepfakes. The framework resolves the classical blindness-robustness paradox and geometric desynchronization by integrating low-frequency 2D Haar DWT sub-band decomposition, Singular Value Decomposition (SVD), Quantization Index Modulation (QIM), dual-layer cryptography, and feature-based pre-alignment.

System Architecture Pipeline (5 Phases)

The end-to-end framework comprises five synchronized processing phases:

Phase 1: Cryptographic & Visual Preparation

Phase 01

Payload protection using dual-layer encryption to ensure steganalysis resistance.

Plaintext Message (M) → AES-256 CBC + PKCS7 Padding → 32-bit Header Assembly → Text-to-Visual Matrix (Iw) → Logistic Map Chaos Scrambling (μ=3.99)

Phase 2: Host Image Decomposition

Phase 02

Frequency-domain isolation and geometric reference anchor generation.

Cover Image (R, G, B) → 96x96 Reference Anchor Thumbnail (T) → 2D Haar DWT (CB, CG, CR) → Extract LL Sub-band → Partition into n × n Non-overlapping Blocks

Phase 3: Adaptive Hybrid Embedding

Phase 03

Dual-layer matrix projection combined with scalar quantization.

Block SVD Factorization → Local Variance (σ2) HVS Masking (αi,j) → Layer 1: Structural Matrix Fusion (Σ'c) → Layer 2: QIM Payload Modulation (s''1) → Inverse SVD Synthesis

Phase 4: Image Reconstruction

Phase 04

Frequency synthesis and color-space clipping protection.

Modified LL' Sub-band → Inverse 2D-DWT Filter Bank → Channel Merging (C'B, C'G, C'R) → 8-bit Space Clipping → Watermarked Stego Image

Phase 5: Zero-Knowledge Blind Extraction

Phase 05

Geometric realigning, parity extraction, and symmetric decryption.

Attacked Image (Iattacked) → ORB-RANSAC Feature Alignment (8-DOF Homography) → DWT-SVD Sub-band Extraction → QIM Parity Bit Extraction → 9× Majority Voting → AES-256 Decryption → Recovered Message (M)
