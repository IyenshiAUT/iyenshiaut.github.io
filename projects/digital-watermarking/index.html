ChromaGuard Pro: Robust & Adaptive Blind Image Watermarking Framework

PythonDWT-SVDQIMAES-256 EncryptionChaotic ScramblingORB-RANSACSignal Processing

Overview

ChromaGuard Pro is a robust, adaptive, and zero-knowledge blind invisible image watermarking framework designed for content provenance, forensic tracking, and protection against generative AI deepfakes. The framework resolves the classical blindness-robustness paradox and geometric desynchronization by integrating low-frequency 2D Haar DWT sub-band decomposition, Singular Value Decomposition (SVD), Quantization Index Modulation (QIM), dual-layer cryptography, and feature-based pre-alignment.

Core Methodology & Architecture

  • Block-Variance Adaptive DWT-SVD & QIM Embedding: Computes a local block variance (σ2) Human Visual System (HVS) masking factor to dynamically confine watermark embedding to high-texture blocks, achieving an unattacked PSNR of 39.92 dB and SSIM of 0.9992. Singular values of the DWT LL sub-band are modulated via QIM with 9× multi-channel majority voting redundancy.
  • Dual-Layer Cryptographic Security: Payload bits are encrypted using AES-256 in Cipher Block Chaining (CBC) mode with PKCS7 padding, followed by 1D Logistic Map chaotic scrambling (μ = 3.99) to eliminate structural spatial correlations and thwart spatial steganalysis.
  • ORB-RANSAC Feature Pre-Alignment: Utilizes Oriented FAST and Rotated BRIEF (ORB) feature matching with Random Sample Consensus (RANSAC) to estimate an 8-DOF homography matrix (H) against a geometric anchor thumbnail, restoring grid alignment and defeating rotational (10°) and spatial scaling attacks prior to extraction.
  • Zero-Knowledge Blind Extraction: Payload extraction relies purely on quantization parity and symmetric key decryption without requiring access to the original cover image.

Key Contributions & Experimental Results

  • Extensive Benchmark: Evaluated across 210 standard images from the USC-SIPI database (6,300 total evaluations across 5 attack conditions), significantly outperforming baseline DCT, DWT, DWT-SVD, LSB, and standalone QIM schemes.
  • High Visual Quality: Maintained an unattacked peak PSNR of 39.92 dB and post-attack average PSNR of 33.09 dB with an average SSIM of 0.7403.
  • Robust Attack Resilience: Achieved low Bit Error Rates (BER) under heavy JPEG compression (Q = 50, BER = 0.2230), Gaussian noise (σ = 10, BER = 0.2582), 5×5 blur (BER = 0.2914), and 10° geometric rotation (BER = 0.4107).
  • High Message Recovery Rate (MRR): Reached 45.71% 100% error-free payload string recovery under lossy JPEG (Q = 50) and 37.14% under Gaussian noise via 9× majority voting.
